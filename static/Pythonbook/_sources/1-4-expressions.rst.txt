1.4 Expressions
::::::::::::::::::::

--------------------------------
Python Operators and Expressions
--------------------------------
Python allows you to combine data with operators using expressions.
For example, here is an assignment statement with a variable name on the left
and an arithmetic expression on the right:

::

    BodyMassIndex = weight/(height**2)

The expression does arithmetic on some variables and the assignment (``=``)
labels the result with the variable name ``BodyMassIndex``

The operators used in the expression are a division (``/``) and exponentiation (``**``).
