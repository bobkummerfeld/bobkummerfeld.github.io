1.3 Variables
:::::::::::::::::::::::

--------------
Variable names
--------------
When you work with data in a program you usually have to give it a name.
We call the name of a particular piece of data a *variable name*.
When we want to name a piece of data we use an *assignment statement* like this:

::

    temperature = 25

What this statement is doing is give the value object (25) a label (temperature).

Whenever you want to refer to your data you just give the variable name.

Python variable names have to follow some rules.
The name must **start** with upper/lower case alphabetic or an underscore.
It can only continue with alphabetics/numbers/underscore.
It **cannot** contain a space or special characters!
